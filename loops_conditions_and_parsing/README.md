# Loops, Conditions and Parsing

Bash scripting exercises covering loops, conditions, and parsing.

## Files

| File | Description |
|------|-------------|
| `1-for_best_school` | Displays "Best School" 10 times using a `for` loop |

## Usage

    ./1-for_best_school

## Requirements

- Ubuntu with Bash
- First line of each script: `#!/usr/bin/env bash`
- Second line of each script: a comment explaining what it does
