# Loops, Conditions and Parsing

Bash scripting exercises covering loops, conditions, and parsing.

## Files

| File | Description |
|------|-------------|
| `1-for_best_school` | Displays "Best School" 10 times using a `for` loop |
| `2-while_best_school` | Displays "Best School" 10 times using a `while` loop |
| `3-until_best_school` | Displays "Best School" 10 times using an `until` loop |
| `4-if_9_say_hi` | Displays "Best School" 10 times, with "Hi" after the 9th, using `while` and `if` |
| `5-4_bad_luck_8_is_your_chance` | Displays "bad luck" on the 4th, "good luck" on the 8th, "Best School" otherwise, using `while`, `if`, `elif`, `else` |
| `6-superstitious_numbers` | Displays 1 to 20 with bad luck messages for 4, 9 and 17, using `while` and `case` |

## Usage

    ./1-for_best_school

## Requirements

- Ubuntu with Bash
- First line of each script: `#!/usr/bin/env bash`
- Second line of each script: a comment explaining what it does
